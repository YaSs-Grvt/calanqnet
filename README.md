# CALANQ'NET — projet BUT3 Réseaux & Télécommunications

Projet d'étude, de conception, de maquettage et d'implémentation de l'architecture systèmes et réseaux du bâtiment R&T de l'IUT de Luminy et de son site jumeau de Digne-les-Bains. CALANQ'NET est une société de conseil fictive créée pour le jeu de rôle du projet.

**Site du projet : https://yass-grvt.github.io/calanqnet/**

| Dossier | Contenu |
|---|---|
| `index.html`, `assets/` | Site vitrine de CALANQ'NET (société, offre, équipe, journal de bord) |
| `reservation/` | Prototype Réserv'Salles : salles libres, planning par salle, réservation sans conflit |
| `docs/` | Journal de bord et planning par phases |
| `configs/maquette_packet_tracer` | Configurations de la maquette Packet Tracer (LAN, datacenter, WAN, Internet) |
| `configs/maquette_securite_voix` | Pare-feu ASA, compléments de sécurité des commutateurs, téléphonie CME |
| `configs/production_reference` | Configurations de référence de production (accès, cœur, WAN, bordure Internet) |
| `configs/gns3_mpls_operateur` | Maquette GNS3 optionnelle du cœur MPLS opérateur |
